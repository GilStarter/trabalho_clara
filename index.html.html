    Como funciona

    1. Você denuncia. Informa o local, anexa o que tiver e descreve o que viu.
    2. A equipe faz a triagem. Cada relato recebe uma gravidade e um status: pendente, em análise, encaminhada ou resolvida.
    3. O caso é encaminhado. Segue em formato padronizado para o órgão competente.
    4. Você acompanha. Use o protocolo para ver o histórico.
